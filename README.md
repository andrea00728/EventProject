# EventProject

Ce projet est une application complète de **gestion d'organisation d'événements**, composée d’un frontend (React + Vite) et d’un backend (NestJS).

## 📁 Structure du projet

Une fois le projet cloné, vous trouverez deux répertoires :

- `frontend/` — Interface utilisateur (React + Vite)
- `backend/` — API REST (NestJS)

---

## ⚙️ Prérequis

Installez **Node.js v18.16.0** (recommandé pour la stabilité).

> ℹ️ Les versions récentes de Node.js peuvent provoquer des bugs avec certaines anciennes dépendances.  
> C'est pourquoi nous avons choisi **v18.16.0** pour éviter les problèmes de compatibilité.
